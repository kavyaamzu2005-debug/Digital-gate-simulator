# Digital-gate-simulator


An interactive web-based **Digital Gate Simulator** built using **HTML, CSS, and JavaScript**.

This project allows users to simulate different digital logic gates and arithmetic circuits by changing the input values and observing the output instantly.

##  Features

### Logic Gates
- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate
- XNOR Gate

### Arithmetic Circuits
- Half Adder
- Full Adder

### Interactive Features
- Toggle input values between 0 and 1
- Automatically calculates outputs
- Displays the corresponding logic expression
- Dynamic truth tables
- Highlights the current input combination
- Simple and responsive user interface

##  Logic Circuits Covered

### AND Gate
Output is `1` only when both inputs are `1`.

### OR Gate
Output is `1` when at least one input is `1`.

### NOT Gate
Produces the opposite of the input.

### NAND Gate
Produces the opposite output of an AND gate.

### NOR Gate
Produces the opposite output of an OR gate.

### XOR Gate
Output is `1` when the inputs are different.

### XNOR Gate
Output is `1` when the inputs are the same.

### Half Adder

A Half Adder adds two binary inputs.

**Inputs:**
- A
- B

**Outputs:**
- SUM
- CARRY

Formulas:

```text
SUM = A XOR B
CARRY = A AND B
